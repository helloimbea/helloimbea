# Hello, I'm Bea! 👋

> *Thinking, building, and dreaming.* ✨

I'm **Beatriz Heimann Gesser**, a developer from **Santa Catarina, Brazil** 🇧🇷, currently at **Bosch** and studying **Analysis and Systems Development** at **SENAC**. My focus is **full-stack web development** with **Angular, TypeScript, C# / ASP.NET Core, and REST APIs**.

Before code, there was art: I'm also a **digital artist** 🎨 (Procreate, Procreate Dreams, Krita, Clip Studio), and that's where my love for **UI/UX** comes from. I like building interfaces that are intuitive, accessible, and a little cozy, and I enjoy owning projects end to end, from the idea and the visual identity to the code.

## 📌 Featured Projects

### Personal Projects

- 🍕 **[Bosch Pizza](https://github.com/helloimbea/boschPizza)** – Full-stack pizza management system built with **Angular** and **ASP.NET Core (C#)**: user registration and login, **JWT** authentication, role-based access (Admin & User), customer management, a dashboard, and a SQL database I designed myself.

- 📖 **[My Cozy Bookshelf](https://github.com/helloimbea/MyCozyBookshelf)** – A private, cozy bookshelf where each reader keeps the books they've read and the reflections each one left behind: a sentence that stuck, a feeling, something that changed after reading. Built with **TypeScript**.

- 📚 **[Ajuda.me](https://github.com/helloimbea/ajudame)** – Front end of a creative online bookstore for **self-help, philosophy, and psychology** books, with a visual identity I created from scratch.

- 🦆 **[Pato vs. Torrada](https://github.com/helloimbea/Pato-vs.-Torrada)** – A 2D clicker game made with **Python** and **Pygame** for the Apps and Games course at SESI. I did everything: concept, mechanics, code, art, UI, and game design.

- 🧠 **[Clinical Psychologist Website](https://github.com/helloimbea/site-psicologa-clinica)** – A welcoming landing page for a clinical psychology practice.

### Academic & Course Projects

- 📊 **[PI – Data Science](https://github.com/helloimbea/PI-ciencia-de-dados)** – Integrator Project for the Analysis and Systems Development program at SENAC, using **Python** and **Jupyter Notebooks**.

- 📮 **[BuscaCEP](https://github.com/helloimbea/API-cep)** – Angular app that looks up Brazilian postal codes through a public API, built with Ana Julya during Front-end classes at Bosch.
